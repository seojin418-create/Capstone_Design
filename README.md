# 성남시 수정구 500 m 격자별 침수 취약도

가천대학교 캡스톤디자인 최종보고서 「빗물이용시설의 침수 취약지 부합도 점검 — 성남시 수정구」(김찬영 · 이서진)의 부록 B · C · D를 웹페이지로 옮긴 것입니다.

- 수정구를 500 m 격자 220칸으로 나누고, 표고 · 경사 · 시가화 비율을 1~5점으로 매겨 평균(지수)으로 등급을 나눴습니다.
- 지도에서 격자를 누르면 그 격자의 값과 점수, 격자 안 빗물이용시설이 나옵니다.
- 아래 표는 보고서 표 B-1(빗물이용시설 38개소 판정), C-1(법적시설 7개소 건축물대장), D-1(격자별 지표 점수)과 같은 값이며 CSV로 받을 수 있습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 대시보드 페이지 |
| `data/grid.geojson` | 220개 격자와 점수 |
| `data/facilities.geojson` | 위치를 확인한 빗물이용시설 24곳과 판정 |
| `data/facilities_38.csv` | 38개소 판정표 (보고서 표 B-1) |
| `data/legal_7.csv` | 법적시설 7개소 건축물대장과 시설 현황 (보고서 표 C-1) |
| `data/boundary.geojson` | 수정구 경계 |
| `data/appendix_D_220grid.csv` | 격자별 지표 점수 (보고서 표 D-1) |
